# 音声ブリーフの公開確認

ホーム `/yui` の「今日のまとめ」から約1・3・5分を選んで生成する。
所要時間は原稿量による目安。材料が少ないときは短くする。
当日の記録、過去の記憶、直近のまとめから原稿を作り、推測は断定しない。

Google Calendarは通知設定とは別に6時間ごとに同期する。直近の同期を待てない場合は、連携設定の「今すぐ同期」を使う。

## 本番設定

Vercelの `yohakuos2` → Settings → Environment Variables → Productionに登録する。
キーの値をチャット、ソース、Gitに貼らない。

- `MANAGED_GEMINI_API_KEY`: YOHAKU本番用のGeminiキー。
- `GOOGLE_TTS_API_KEY`: Google Cloud Text-to-Speech APIを有効にした課金プロジェクトの専用キー。API制限はText-to-Speechに設定する。

キー登録後は今回の変更を含むデプロイが必要。旧デプロイの再実行だけではローカルのコード変更は入らない。

## 料金・再生

- Premiumのみ。無料ユーザーのAPI要求もサーバーで拒否する。
- 1分: 原稿最大1回と音声1回でAI利用枠最大2回。
- 3分: 原稿最大3回と音声1回で最大4回。
- 5分: 原稿最大4回と音声1回で最大5回。
- 原稿が途中で終了した場合、その時点までの生成分を計上する。
- 音声が途中で失敗しても完成した原稿・音声を返す。音声APIへの送信後は課金の可能性があるため予約を維持する。
- 画面内の再生は追加生成しない。音声は端末の一時URLで保持し、画面を離れると破棄する。再訪時の再生成は利用枠を使う。

## 実接続確認（未実施）

1. 無料アカウントで生成要求が403となり、外部AIへ送信されないこと。
2. Premiumで1分を生成し、原稿と音声が一致すること。再生、一時停止、再生位置の変更を確認する。
3. 3分・5分で章が順に再生され、最終章で止まること。スマートフォンでも確認する。
4. 記録の日付・引用が正しく、予定を完了扱いにせず、関連性の仮説が断定されないこと。
5. 前回以降の記録がない振り返りは新規保存されず、新しい記録があると内容が更新されること。
6. 利用上限・API失敗時に完成した原稿が表示され、同じ画面で再生しても利用枠が増えないこと。

型チェック・ビルドの成功は、声質・再生時間・生成内容の品質を保証しない。実際の試聴で確認する。
